# RAG Assistant - Local PDF Question Answering System

## Overview

RAG Assistant is a Retrieval-Augmented Generation (RAG) application that enables users to ask natural language questions about PDF documents and receive context-aware answers generated by a local Large Language Model (LLM).

The system combines semantic document retrieval using vector embeddings with local inference through Ollama, allowing users to query documents without relying on cloud-based AI services.

All processing runs locally, providing improved privacy and control over sensitive data.

---

## Features

* PDF document ingestion and indexing
* Semantic search using vector embeddings
* Retrieval-Augmented Generation (RAG)
* Local LLM inference via Ollama
* FastAPI-powered REST API
* Source tracking for retrieved document chunks
* Fully offline workflow
* Lightweight and easy to deploy

```text
      │
      ▼
Embedding Generation
(all-MiniLM-L6-v2)
      │
      ▼
Chroma Vector Database
      │
      ▼
Similarity Search
      │
      ▼
Retrieved Context
      │
      ▼
Ollama LLM (Gemma 2B)
      │
      ▼
Generated Answer
```

## Installation

### 1. Clone Repository

```bash
git clone <repository-url>
cd RAG_assistant
```

### 2. Create Virtual Environment

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Install Ollama

Download and install:

https://ollama.com

Pull the model:

```bash
ollama pull gemma:2b
```

## How It Works

1. PDF files are loaded into memory.
2. Documents are split into manageable chunks.
3. Each chunk is converted into vector embeddings.
4. Embeddings are stored in ChromaDB.
5. User questions are converted into embeddings.
6. Relevant document chunks are retrieved using semantic similarity.
7. Retrieved context is sent to Ollama.
8. The model generates an answer grounded in the retrieved documents.

## Why RAG?

Traditional language models rely solely on pre-trained knowledge.

RAG improves accuracy by retrieving relevant information from external documents before generating responses, making answers more reliable, up-to-date, and document-grounded.
